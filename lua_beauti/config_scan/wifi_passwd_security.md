# wifi_passwd_security.lua - WiFi 密码强度检测模块

## 工作原理

本模块检测路由器 WiFi 密码的安全强度。强密码是防止未授权访问的第一道防线。

### 密码强度评估标准

密码必须满足以下条件才被认为是强密码：
1. 长度至少 8 个字符
2. 包含以下至少 2 种字符类型：
   - 数字 (0-9)
   - 小写字母 (a-z)
   - 大写字母 (A-Z)
   - 特殊字符

### 密码示例

| 密码 | 强度 | 原因 |
|------|------|------|
| 12345678 | 弱 | 纯数字 |
| password | 弱 | 纯小写字母 |
| abcd1234 | 弱 | 仅两种类型但复杂度不足 |
| MyP@ssw0rd | 强 | 混合大小写、数字、特殊字符 |
| Secure#2024! | 强 | 长度足够，复杂度高 |

## 接口

### 函数

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `overview()` | - | table | 获取扫描概览信息，包含 enable_scan 字段 |
| `prepare(statusPath)` | statusPath: 状态文件路径 | - | 准备扫描环境 |
| `scan(statusPath)` | statusPath: 状态文件路径 | number | 执行扫描，返回 0(不安全) 或 1(安全) |

### 扫描结果

| 结果 | 说明 |
|------|------|
| 0 | 不安全（密码强度不足） |
| 1 | 安全（密码强度足够） |
