# XQBrUtil.lua - 网桥工具模块

## 概述

`XQBrUtil` 模块提供 Linux 网桥（bridge）的 MAC 地址表读取和端口映射功能。该模块通过读取 `/sys/class/net/<bridge>/brforward` 文件获取网桥的 MAC 转发表，用于设备发现和网络诊断。

## 工作原理

```
┌─────────────────────────────────────────────────────────────┐
│                    Linux网桥MAC表读取                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │
│  │   网桥接口   │───▶│   端口映射   │───▶│   MAC表     │  │
│  │ br-lan/guest │    │  port_no    │    │  brforward  │  │
│  └──────────────┘    └──────────────┘    └──────────────┘  │
│         │                   │                   │          │
│         ▼                   ▼                   ▼          │
│  ┌──────────────────────────────────────────────────────┐  │
│  │              /sys/class/net/<bridge>/                 │  │
│  │  • brif/<ifname>/port_no  - 端口号                   │  │
│  │  • brforward              - MAC转发表                │  │
│  │    格式: 端口号;MAC地址;是否本地;老化时间             │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 接口列表

### get_macs(bridge)

获取网桥的 MAC 地址表。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| bridge | string | 网桥名称 (如 "br-lan", "br-guest") |

**返回值:**
| 字段 | 类型 | 说明 |
|------|------|------|
| [].no | string | 端口号 |
| [].dev | string | 接口设备名 |
| [].mac | string | MAC 地址 |
| [].is_local | string | 是否本地地址 (1=本地, 0=学习到的) |
| [].ageing | string | 老化时间（秒） |

---

### get_port_map(bridge)

获取网桥端口号到接口名的映射。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| bridge | string | 网桥名称 |

**返回值:**
| 类型 | 说明 |
|------|------|
| table | 端口号(number)到接口名(string)的映射表 |

---

### print_br_macs(bridge)

打印网桥 MAC 地址表（调试用）。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| bridge | string | 网桥名称 |

**返回值:** 无（直接打印到控制台）

---

### print_all_macs()

打印所有网桥（br-lan, br-guest）的 MAC 地址表。

**参数:** 无

**返回值:** 无

## 关键代码说明

### brforward 文件格式

```
端口号;MAC地址;是否本地;老化时间
```

- 端口号：网桥内部端口编号
- MAC 地址：设备的 MAC 地址
- 是否本地：1 表示本地接口地址，0 表示学习到的远端地址
- 老化时间：MAC 条目的老化计时器（秒）

### 端口映射获取

```lua
local port_file = "/sys/class/net/" .. bridge .. "/brif/" .. ifname .. "/port_no"
local port_no = file:read("*a")
port_map[tonumber(port_no)] = ifname
```

通过读取每个网桥接口的 `port_no` 文件建立端口号到接口名的映射关系。
