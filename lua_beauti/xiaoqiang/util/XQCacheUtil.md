# XQCacheUtil.lua - 缓存工具模块

## 概述

`XQCacheUtil` 模块提供基于文件的缓存机制，支持缓存过期时间设置。缓存数据存储在 `/tmp` 目录下，使用 Lua 字节码序列化数据，适用于临时数据的快速存取。

## 工作原理

│                      文件缓存机制                            │
├─────────────────────────────────────────────────────────────┤

│  │  saveCache   │───▶│  序列化数据  │───▶│  写入文件    │  │
│  │   保存缓存   │    │  bytecode   │    │  /tmp/key    │  │

│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐  │

│  └──────────────┘    └──────────────┘    └──────────────┘  │

## 接口列表

### saveCache(key, data, expire)

保存缓存数据。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| key | string | 缓存键名 |
| data | any | 要缓存的数据 |
| expire | number | 过期时间（秒），0 表示永不过期 |

**返回值:**
| 类型 | 说明 |
|------|------|
| boolean | 是否保存成功 |

---

### getCache(key)

获取缓存数据（过期自动删除）。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| key | string | 缓存键名 |

**返回值:**
| 类型 | 说明 |
|------|------|
| any/nil | 缓存的数据，过期或不存在返回 nil |

---

### getCacheData(key)

获取缓存数据（带活跃状态）。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| key | string | 缓存键名 |

**返回值:**
| 字段 | 类型 | 说明 |
|------|------|------|
| data | any | 缓存的数据 |
| active | number | 活跃状态 (1=活跃, 0=已过期) |

---

### rmCacheData(key)

删除缓存数据。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| key | string | 缓存键名 |

**返回值:**
| 类型 | 说明 |
|------|------|
| boolean | 是否删除成功 |

## 关键代码说明

### 字节码序列化

```lua
file:writeall(luci_util.get_bytecode(cache_data))
```

使用 `luci.util.get_bytecode` 将 Lua 表序列化为字节码，比 JSON 序列化更高效，且能保存 Lua 原生数据类型。

### 过期检测

```lua
local expire_at = cache_data.atime + cache_data.expire
local current_time = luci_sys.uptime()

if expire_at < current_time then
    fs.unlink(cache_path)
    return nil
end
```

使用系统运行时间（uptime）而非墙上时钟时间，避免系统时间变更导致的缓存异常。

### 反序列化

```lua
local func = loadstring(content)
setfenv(func, {})  -- 安全沙箱
local cache_data = func()
```

使用 `loadstring` 加载字节码，并设置空环境防止代码注入。
