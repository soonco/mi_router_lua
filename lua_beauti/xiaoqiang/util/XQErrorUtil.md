# XQErrorUtil.lua - 错误工具模块

## 概述

`XQErrorUtil` 模块提供错误码到错误消息的映射功能。所有错误消息支持国际化翻译，通过 `_()` 函数标记可翻译字符串。该模块定义了系统中使用的所有标准错误码。

## 工作原理

```
│  │   (number)   │    │ errorMessages│    │  translate() │  │
│  └──────────────┘    └──────────────┘    └──────────────┘  │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │                    错误码分类                         │  │
│  │  1501-1599: 系统/配置错误                            │  │
│  │  1600-1699: 开发者/权限错误                          │  │
│  │  1800-1899: 短信/通信错误                            │  │
│  │  2500-2599: 插件错误                                 │  │
│  │  2600-2699: IPv6 错误                                │  │

│  └──────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 接口列表

### getErrorMessage(errorCode)

根据错误码获取错误消息。

**参数:**
| 参数 | 类型 | 说明 |
|------|------|------|
| errorCode | number | 错误码 |

**返回值:**
| 类型 | 说明 |
|------|------|
| string | 翻译后的错误消息，未知错误码返回 "未知错误" |

## 关键代码说明

### 国际化标记

```lua
[1502] = _("输入不能够为空"),
```

使用 `_()` 函数标记可翻译字符串，LuCI 框架会根据当前语言设置自动翻译。

### 未知错误处理

```lua
if message == nil then
    return translate(_("未知错误"))
else
    return translate(message)
end
```

对于未定义的错误码，返回通用的 "未知错误" 消息。

### 错误码设计规范

- 1500-1999: 基础系统错误
- 2500-2999: 功能模块错误
- 3000+: 特殊功能冲突错误

每个功能模块分配 100 个错误码空间，便于扩展和管理。
