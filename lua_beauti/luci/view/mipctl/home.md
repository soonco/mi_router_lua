# home.htm - 家人上网保护拦截页面

## 文件作用
当用户访问被家长控制功能拦截的网站时显示此页面，告知用户访问被拦截的原因。

## 使用的 API

### Lua 模块
| 模块 | 说明 |
|------|------|
| `xiaoqiang.XQVersion` | 获取 Web 版本号 |

## 页面原理

### 拦截原因
页面展示三种可能的拦截原因：
1. **禁止上网时段** - 当前时间处于家长设置的禁止上网时段
2. **关键字过滤** - 访问的网址被设置的关键字规则匹配
3. **使用时长限制** - 相关应用的今日使用时长已达上限

### 页面结构
- 拦截提示图标
- 拦截说明标题
- 详细原因列表

## 依赖关系
- `web/inc/head` - 页面头部
- `web/inc/footer` - 页面尾部
- `web/css/bc.css` - 基础样式
- `mipctl/css/mipctl.css` - 拦截页专用样式

## 关键代码说明

### 响应式设计
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">
```
页面支持移动端自适应显示。

### 静态展示
此页面为纯展示页面，不包含交互逻辑，用户需要通过米家APP或路由器管理后台调整家长控制设置。
