# box.htm.htm - Samba设置HTML模板

## 文件作用
提供 Samba 文件共享服务的配置界面，包含用户名和密码设置表单。

## 页面原理

### 界面结构
1. **用户名输入框**: 固定为 root，禁用编辑
2. **密码输入框**: 用于设置 Samba 密码
3. **保存按钮**: 保存密码设置
4. **重启按钮**: 重启 Samba 服务

### 表单字段
| 字段 | ID | 说明 |
|------|-----|------|
| 用户名 | user | 固定为 root，不可编辑 |
| 密码 | pass | Samba 访问密码 |

### 默认值
- 用户名: root
- 密码: 默认 password（提示文字）

## 依赖关系
- `box.js.htm` - 交互逻辑
- `box.css.htm` - 样式定义
- `box.lua.htm` - 后端处理

## 使用说明
1. 输入新密码
2. 点击"保存"按钮
3. 点击"重启"按钮使配置生效
4. 使用 `\\路由器IP` 访问共享
