# box.lua.htm - 磁盘分区管理后端逻辑

## 文件作用
提供磁盘分区管理功能的服务端处理逻辑，通过 ttyd 终端工具启动 cfdisk 分区工具。

## 使用的 API

### Lua 模块
| 模块 | 说明 |
|------|------|
| `luci.http` | HTTP 请求处理 |
| `luci.sys` | 系统命令执行 |

### 系统命令
| 命令 | 说明 |
|------|------|
| `kill` | 终止进程 |
| `ttyd` | Web 终端工具 |
| `cfdisk` | 磁盘分区工具 |
| `uci get` | 读取 UCI 配置 |

## 页面原理

### 处理流程
1. 获取 HTTP 请求参数 `mac`
2. 清理已存在的 ttyd 进程（端口 53077）
3. 当 `mac=cfdisk_run` 时：
   - 复制 cfdisk 依赖库到临时目录
   - 设置 cfdisk 执行权限
   - 启动 ttyd 运行 cfdisk
4. 返回 JSON 格式的执行状态

### 端口配置
- 固定使用端口 **53077**
- 启动前会清理该端口的旧进程

### 返回格式
```json
{
    "statu": 1,      // 1=成功, 0=失败
    "prot": 53077,   // 端口号
    "info": "..."    // 状态信息
}
```

## 依赖关系
- `xxx_ttyd` - Web 终端工具
- `cfdisk` - 磁盘分区工具
- `cfdisk/lib/*` - cfdisk 依赖库
- UCI 配置 `lyq.xxx_path`

## 安全警告
磁盘分区操作具有高风险，错误操作可能导致数据丢失，请谨慎使用。
