# box.htm.htm - 网络唤醒HTML模板

## 文件作用
提供 Wake-on-LAN 网络唤醒功能的用户界面，包含配置编辑和服务控制。

## 使用的 API

### Lua 模块
| 模块 | 说明 |
|------|------|
| `luci.sys` | 系统命令执行 |

## 页面原理

### 界面结构
1. **标题**: "wol 客户端配置信息"
2. **配置编辑区**: 多行文本框显示 YAML 配置
3. **操作按钮**:
   - 保存 - 保存配置文件
   - 重启 - 重启 WOL 服务

### 配置加载
```lua
<%=luci.sys.exec("cat $(uci get lyq.xxx_path)/xxxbox/wol/config.yaml")%>
```
读取并显示当前的 WOL 配置文件内容。

### 配置格式
使用 YAML 格式配置，通常包含：
- 设备名称
- MAC 地址
- 广播地址

## 依赖关系
- `box.js.htm` - 交互逻辑
- `box.css.htm` - 样式定义
- `box.lua.htm` - 后端处理

## 使用说明
1. 编辑 YAML 配置文件
2. 点击"保存"按钮
3. 点击"重启"使配置生效
