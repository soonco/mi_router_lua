# box.js.htm - UCI编辑器JavaScript逻辑

## 文件作用
提供 UCI 配置编辑器的前端交互逻辑，实现搜索、过滤和保存功能。

## 全局变量
| 变量 | 说明 |
|------|------|
| `uci_strarr` | 存储所有 UCI 配置项的数组 |

## 核心函数

### search_click()
搜索按钮点击处理：
1. 发送 AJAX 请求获取所有 UCI 配置
2. 验证数据有效性（包含 "xiaoqiang"）
3. 按换行符拆分为数组
4. 过滤匹配搜索关键字的项（最多5条）
5. 动态生成编辑表单

### search_change()
实时过滤功能：
1. 从已加载的配置数组中过滤
2. 匹配搜索关键字
3. 更新显示结果（最多5条）

### save_butt_click()
保存按钮点击处理：
1. 收集所有修改的配置项
2. 拼接为 `key=value!@.@!` 格式
3. Base64 编码后发送到后端
4. 保存成功后重新搜索刷新

## 页面原理

### 配置项格式
```
key=value
```
显示为：`[key输入框] = [value输入框]`

### 限制说明
- 每次最多显示 5 条匹配结果
- 仅显示包含 `=` 的有效配置项

## 依赖关系
- `ajaxPost()` - AJAX 请求函数
- `btoa()` - Base64 编码
- `encodeURIComponent()` - URL 编码
