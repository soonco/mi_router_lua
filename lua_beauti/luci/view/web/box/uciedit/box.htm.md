# box.htm.htm - UCI编辑器HTML模板

## 文件作用
提供 UCI 配置编辑器的用户界面，支持搜索和修改 UCI 配置项。

## 页面原理

### 界面结构
1. **标题**: "UCI 编辑器"
2. **搜索区域**:
   - 搜索输入框
   - 搜索按钮
3. **结果区域**: 动态显示匹配的配置项

### 交互流程
1. 用户输入搜索关键字
2. 点击搜索或实时过滤
3. 显示匹配的配置项（最多5条）
4. 用户修改配置值
5. 点击保存提交更改

### AJAX 标记
```html
<!-- uciedit_box_ajax_start -->
<!-- uciedit_box_ajax_end -->
```
用于标记可动态更新的内容区域。

## 依赖关系
- `box.js.htm` - 交互逻辑
- `box.css.htm` - 样式定义
- `box.lua.htm` - 后端处理

## 使用说明
1. 输入配置项关键字（如 network、wireless）
2. 点击搜索加载配置
3. 修改需要更改的值
4. 点击保存应用更改
