# box.lua.htm - 网速测试后端逻辑

## 文件作用
提供网速测试功能的服务端处理逻辑，通过 ttyd 终端工具执行网速测试脚本。

## 使用的 API

### Lua 模块
| 模块 | 说明 |
|------|------|
| `luci.http` | HTTP 请求处理 |
| `luci.sys` | 系统命令执行 |

### 系统命令
| 命令 | 说明 |
|------|------|
| `kill` | 终止进程 |
| `ttyd` | Web 终端工具 |
| `uci get` | 读取 UCI 配置 |

## 页面原理

### 处理流程
1. 获取 HTTP 请求参数 `mac`
2. 清理已存在的 ttyd 进程（端口 37635）
3. 当 `mac=speedtest_run` 时启动网速测试
4. 返回 JSON 格式的执行状态

### 端口配置
- 固定使用端口 **37635**
- 启动前会清理该端口的旧进程

### 返回格式
```json
{
    "statu": 1,      // 1=成功, 0=失败
    "prot": 37635,   // 端口号
    "info": "..."    // 状态信息
}
```

## 依赖关系
- `xxx_ttyd` - Web 终端工具
- `speedtest/call.sh` - 网速测试脚本
- UCI 配置 `lyq.xxx_path`

## 功能说明
网速测试功能通过 Web 终端展示测试过程和结果，支持测试上传和下载速度。
