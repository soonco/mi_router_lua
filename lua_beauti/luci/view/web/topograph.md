# topograph.htm - 网络拓扑图页面

## 文件作用
显示小米路由器 Mesh 网络的完整拓扑结构，展示主路由和子路由的连接关系。

## 使用的 API

### Lua 模块
| 模块 | 说明 |
|------|------|
| `xiaoqiang.XQVersion` | 获取 Web 版本号 |
| `xiaoqiang.util.XQSysUtil` | 系统工具 |

## 页面原理

### 拓扑结构
使用树形结构展示网络：
```
互联网
  └── 主路由器（网关）
        ├── 子路由器1
        │     └── 终端设备
        └── 子路由器2
              └── 终端设备
```

### 模板系统
使用 JavaScript 模板渲染拓扑节点：
- `#rootroutertpl` - 主路由器模板
- `#routertpl` - 子路由器模板

### 动态图标
- 鼠标悬停时切换高亮图标
- 显示每个路由器的在线设备数
- 支持点击跳转到对应路由器管理页

## 依赖关系
- `web/inc/head` - 页面头部
- `web/inc/footer` - 页面尾部
- `web/css/bc.css` - 基础样式
- `web/css/topograph.css` - 拓扑图样式

## 页面功能

### 显示信息
- 互联网连接状态
- 各路由器名称和位置
- 设备在线数量
- 连接方式（有线/无线）

### 交互功能
- 点击路由器图标跳转到对应管理页
- 鼠标悬停显示详细信息
- 支持 Mesh 网络的完整展示

## 适用场景
- Mesh 组网环境
- 多路由器级联
- 网络结构可视化
