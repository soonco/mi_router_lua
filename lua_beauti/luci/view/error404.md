# error404.htm - 404错误页面模板

## 文件作用
当用户访问的路由路径不存在时，LuCI 框架会渲染此模板，向用户展示 404 Not Found 错误信息。

## 使用的 API
| API | 说明 |
|-----|------|
| `luci.http.request.env.PATH_INFO` | 获取用户请求的路径信息 |

## 页面原理
1. **模板继承**: 使用 `<%+header%>` 和 `<%+footer%>` 引入页面头部和尾部模板
2. **国际化支持**: 使用 `<%:文本%>` 语法支持多语言翻译
3. **错误展示**: 显示 404 状态码和无法分发的请求路径

## 依赖关系
- `header` - 页面头部模板
- `footer` - 页面尾部模板

## 关键代码说明
```lua
<%=luci.http.request.env.PATH_INFO%>
```
此代码获取并显示用户请求的无效路径，帮助用户和开发者定位问题。
