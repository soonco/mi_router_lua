# error500.htm - 500服务器错误页面模板

## 文件作用
当服务器发生内部错误时，LuCI 框架会渲染此模板，向用户展示 500 Internal Server Error 错误信息及详细错误消息。

## 使用的 API
| API | 说明 |
|-----|------|
| `message` | 服务器传递的错误详情变量 |

## 页面原理
1. **模板继承**: 使用 `<%+header%>` 和 `<%+footer%>` 引入页面头部和尾部模板
2. **国际化支持**: 使用 `<%:文本%>` 语法支持多语言翻译
3. **错误详情**: 在 `<pre>` 标签中展示详细的错误堆栈信息

## 依赖关系
- `header` - 页面头部模板
- `footer` - 页面尾部模板

## 关键代码说明
```html
<pre class="error500"><%=message%></pre>
```
使用预格式化文本展示错误详情，保留错误信息的原始格式，便于调试。
