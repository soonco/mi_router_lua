# tzoffset.lua - 时区偏移量数据模块

## 工作原理

提供各时区缩写与 UTC 偏移量（秒）的映射表。正值表示东时区（UTC+），负值表示西时区（UTC-）。

### 偏移量计算

- 1 小时 = 3600 秒
- UTC+8（如 CST 中国标准时间）= 28800 秒
- UTC-5（如 EST 美国东部标准时间）= -18000 秒

## 接口

| 属性 | 类型 | 说明 |
|------|------|------|
| `OFFSET` | table | 时区缩写到 UTC 偏移量（秒）的映射 |

### 常用时区偏移量

| 缩写 | 偏移量（秒） | UTC 偏移 | 说明 |
|------|-------------|----------|------|
| `gmt` | 0 | UTC+0 | 格林威治标准时间 |
| `cst` | -21600 | UTC-6 | 美国中部标准时间 |
| `est` | -18000 | UTC-5 | 美国东部标准时间 |
| `pst` | -28800 | UTC-8 | 美国太平洋标准时间 |
| `jst` | 32400 | UTC+9 | 日本标准时间 |
| `kst` | 32400 | UTC+9 | 韩国标准时间 |
| `ist` | 19800 | UTC+5:30 | 印度标准时间 |
| `msk` | 14400 | UTC+4 | 莫斯科标准时间 |
| `hkt` | 28800 | UTC+8 | 香港时间 |
| `sgt` | 28800 | UTC+8 | 新加坡时间 |
| `nzst` | 43200 | UTC+12 | 新西兰标准时间 |

### 数据格式

```lua
OFFSET = {
    gmt = 0,
    eat = 10800,    -- 东非时间 UTC+3
    cet = 3600,     -- 中欧时间 UTC+1
    ...
}
```
