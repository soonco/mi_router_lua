# luci/i18n.lua

## 概述

LuCI 国际化（i18n）模块，提供多语言翻译支持。通过加载 `.lmo` 格式的翻译目录文件，实现界面文本的多语言显示。

## 工作原理

1. **语言设置**: `setlanguage()` 设置当前语言，加载对应的翻译目录
2. **翻译查找**: `translate()` 通过 C 模块 `parser` 查找翻译文本
3. **回退机制**: 如果指定语言不存在，尝试加载父语言（如 zh-cn 回退到 zh）
4. **线程本地**: 使用线程本地存储保存当前语言设置

## 接口/函数列表

| 函数 | 参数 | 返回值 | 描述 |
|------|------|--------|------|
| `setlanguage(lang)` | 语言代码 | string | 设置当前语言，返回实际加载的语言 |
| `translate(key)` | 翻译键 | string | 获取翻译文本，无翻译返回原文 |
| `translatef(key, ...)` | 翻译键、格式参数 | string | 获取格式化翻译文本 |
| `string(key)` | 翻译键 | string | 获取翻译文本（转为字符串） |
| `stringf(key, ...)` | 翻译键、格式参数 | string | 获取格式化翻译文本 |
| `clear()` | 无 | void | 清除翻译缓存（空实现） |
| `load(catalog, lang, force)` | 目录名、语言、强制 | void | 加载翻译目录（空实现） |
| `loadc(catalog, force)` | 目录名、强制 | void | 加载翻译目录（空实现） |

## 模块变量

| 变量 | 类型 | 描述 |
|------|------|------|
| `i18ndir` | string | 翻译文件目录路径 |
| `default` | string | 默认语言，"en" |
| `loaded` | table | 已加载的翻译目录 |
| `context` | threadlocal | 线程本地上下文 |
| `table` | table | 翻译表（空） |

## 上下文结构

```lua
context = {
    lang = string,    -- 当前语言代码 (如 "zh-cn")
    parent = string   -- 父语言代码 (如 "zh")
}
```

## 关键代码说明

### 语言设置与回退
```lua
function setlanguage(lang)
    -- 规范化语言代码：zh_CN -> zh-cn
    context.lang = lang:gsub("_", "-")
    
    -- 提取父语言：zh-cn -> zh
    context.parent = context.lang:match("^([a-z][a-z])_")
    
    -- 尝试加载完整语言
    local success = parser.load_catalog(context.lang, i18ndir)
    
    if not success and context.parent then
        -- 回退到父语言
        parser.load_catalog(context.parent, i18ndir)
        return context.parent
    end
    
    return context.lang
end
```

### 翻译查找
```lua
function translate(key)
    local translated = parser.translate(key)
    -- 如果没有翻译，返回原文
    return translated or key
end
```

### 格式化翻译
```lua
function translatef(key, ...)
    local translated = tostring(translate(key))
    -- 使用 string.format 格式化
    return translated:format(...)
end
```

## 翻译文件格式

翻译文件使用 `.lmo` 二进制格式，存储在 `i18ndir` 目录下：
- `base.zh-cn.lmo` - 基础翻译（简体中文）
- `firewall.zh-cn.lmo` - 防火墙模块翻译

## 模板中的使用

```html
<%:Hello World%>           <!-- 翻译 "Hello World" -->
<%:Welcome, %s%> % {name}  <!-- 格式化翻译 -->
```
