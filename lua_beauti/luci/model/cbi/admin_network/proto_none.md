# proto_none.lua - 无协议配置表单模块

## 工作原理

本模块是 LuCI CBI 框架的协议配置表单，用于配置"无协议"(Unmanaged)类型的网络接口。

**核心特点:**
- 表示该网络接口不由系统管理
- 接口存在但不配置任何 IP 地址或协议
- 常用于桥接模式下的从属接口
- 或者由外部程序管理的接口

**使用场景:**
- 纯二层桥接的接口成员
- 由第三方 VPN 软件管理的接口
- 仅用于流量监控的接口

**配置存储:** `/etc/config/network`

## 接口

此协议无需任何配置选项，为空实现。

## 外部引用

无外部依赖。
