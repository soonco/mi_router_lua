# index.lua - 服务模块索引

## 工作原理

服务模块的根节点配置，作为 service 子模块的入口点。创建 `/service` 路由节点，配置管理员认证和 JSON 认证方式，为子模块（cachecenter、datacenter、internal）提供统一的入口。

## 接口

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `index()` | 无 | 无 | 注册服务模块根节点路由 |

### 路由配置

| 路径 | 认证方式 | 说明 |
|------|----------|------|
| `/service` | jsonauth | 服务模块根节点 |

## 外部引用

无外部依赖
