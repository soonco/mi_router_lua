# gateway_security.lua - 网关安全模块

## 工作原理

本模块是小米路由器安全中心的网关安全子模块。它作为一个代理层，将网关安全相关的请求委托给 `luci.controller.anti_attack.index` 模块处理。主要提供防攻击、入侵检测等网关级别的安全功能概览。

## 接口

### 函数

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `_overview()` | - | table | 获取网关安全概览信息 |

## 外部引用

| 模块 | 用途 |
|------|------|
| `luci.controller.anti_attack.index` | 防攻击控制器，提供实际的安全功能实现 |
