# sec_center - 安全中心模块

## 概述

本目录包含小米路由器 LuCI 安全中心的核心模块。安全中心是一个统一的安全管理入口，通过代理模式将各类安全功能的请求委托给相应的底层控制器处理，为用户提供路由器安全状态的综合视图。

## 架构设计

安全中心采用**代理层架构**，各子模块不直接实现具体功能，而是作为统一入口将请求转发给对应的功能控制器。这种设计具有以下优点：

- **解耦合**：安全中心与具体功能实现分离，便于独立维护
- **统一入口**：为用户提供一站式的安全管理界面
- **可扩展**：易于添加新的安全功能模块

```
┌─────────────────────────────────────────────────────────────┐
│                      安全中心 (sec_center)                    │
├─────────────┬─────────────┬─────────────┬─────────────────────┤
│ config_scanner │ content_filter │ gateway_security │    log     │
│   配置扫描     │   内容过滤     │    网关安全      │  安全日志   │
└──────┬──────┴──────┬──────┴──────┬──────┴──────┬──────────────┘
       │             │             │             │
       ▼             ▼             ▼             ▼
┌──────────────┐┌──────────────┐┌──────────────┐┌──────────────┐
│ config_scan  ││   url_fw     ││ anti_attack  ││   milog      │
│   控制器     ││   控制器     ││   控制器     ││   API        │
└──────────────┘└──────────────┘└──────────────┘└──────────────┘
```

## 模块说明

### config_scanner.lua - 配置扫描模块

| 项目 | 说明 |
|------|------|
| **功能** | 检测路由器配置中的安全隐患 |
| **代理目标** | `luci.controller.config_scan.index` |
| **主要接口** | `_overview()` - 获取配置扫描概览信息 |
| **应用场景** | 检查弱密码、不安全的网络配置、开放的危险端口等 |

### content_filter.lua - 内容过滤模块

| 项目 | 说明 |
|------|------|
| **功能** | URL 过滤和访问控制 |
| **代理目标** | `luci.controller.url_fw.index` |
| **主要接口** | `_overview()` - 获取内容过滤概览信息 |
| **应用场景** | 家长控制、网站黑名单、恶意网址拦截等 |

### gateway_security.lua - 网关安全模块

| 项目 | 说明 |
|------|------|
| **功能** | 网关级别的安全防护 |
| **代理目标** | `luci.controller.anti_attack.index` |
| **主要接口** | `_overview()` - 获取网关安全概览信息 |
| **应用场景** | 防 DDoS 攻击、入侵检测、端口扫描防护等 |

### log.lua - 安全日志模块

| 项目 | 说明 |
|------|------|
| **功能** | 安全事件日志记录与查询 |
| **代理目标** | `luci.controller.api.milog` |
| **主要接口** | `_overview()` - 获取日志概览信息 |
| **应用场景** | 查看攻击记录、访问日志、安全告警等 |

## 依赖关系

本模块依赖以下底层控制器：

| 依赖模块 | 路径 | 功能 |
|----------|------|------|
| 配置扫描控制器 | `luci.controller.config_scan.index` | 安全配置检测 |
| URL 防火墙控制器 | `luci.controller.url_fw.index` | URL 过滤功能 |
| 防攻击控制器 | `luci.controller.anti_attack.index` | 攻击防护功能 |
| 小米日志 API | `luci.controller.api.milog` | 日志查询功能 |

## 统一接口

所有子模块都实现了统一的 `_overview()` 接口，返回各自功能的概览信息。这使得安全中心可以通过统一的方式聚合展示所有安全模块的状态。
