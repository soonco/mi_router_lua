# content_filter.lua - 内容过滤模块

## 工作原理

本模块是小米路由器安全中心的内容过滤子模块。它作为一个代理层，将内容过滤相关的请求委托给 `luci.controller.url_fw.index` 模块处理。主要用于家长控制、网站黑名单等 URL 过滤功能。

## 接口

### 函数

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `_overview()` | - | table | 获取内容过滤概览信息 |

## 外部引用

| 模块 | 用途 |
|------|------|
| `luci.controller.url_fw.index` | URL 防火墙控制器，提供 URL 过滤功能 |
