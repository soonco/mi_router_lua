# gf.lua - 伽罗瓦域运算模块

## 工作原理

本模块实现 GF(2^8) 伽罗瓦域（有限域）上的数学运算。AES 加密算法的核心运算都是在 GF(2^8) 上进行的。

### GF(2^8) 基础知识

| 属性 | 值 | 说明 |
|------|-----|------|
| 元素数量 | 256 | 0 到 255 |
| 加法 | XOR | 按位异或 |
| 乘法 | 多项式乘法 | 对不可约多项式取模 |
| 不可约多项式 | x^8 + x^4 + x^3 + x + 1 | 十进制 283 |
| 生成元 | 3 (x + 1) | 用于构建对数表 |

### 对数/指数表优化

为了加速乘法和除法运算，本模块使用预计算的对数表和指数表：

```
如果 g 是生成元，则：
- exp[i] = g^i
- log[a] = i，其中 g^i = a

乘法：a * b = g^(log[a] + log[b]) = exp[(log[a] + log[b]) mod 255]
除法：a / b = g^(log[a] - log[b]) = exp[(log[a] - log[b]) mod 255]
逆元：a^(-1) = g^(255 - log[a]) = exp[255 - log[a]]
```

## 接口

### 主要函数

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `gf.add(a, b)` | 两个字节 | 和 | GF(2^8) 加法（异或） |
| `gf.sub(a, b)` | 两个字节 | 差 | GF(2^8) 减法（与加法相同） |
| `gf.mul(a, b)` | 两个字节 | 积 | GF(2^8) 乘法 |
| `gf.div(a, b)` | 两个字节 | 商 | GF(2^8) 除法 |
| `gf.invert(a)` | 一个字节 | 逆元 | 计算乘法逆元 |

### 调试函数

| 函数 | 说明 |
|------|------|
| `gf.printLog()` | 打印对数表 |
| `gf.printExp()` | 打印指数表 |

### 使用示例

```lua
local gf = require("aeslua.gf")

-- 加法（异或）
local sum = gf.add(0x57, 0x83)  -- = 0xD4

-- 乘法
local product = gf.mul(0x57, 0x83)  -- 使用对数表计算

-- 求逆
local inverse = gf.invert(0x53)  -- 0x53^(-1) in GF(2^8)
```

### 内部配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `config.n` | 256 | 域中元素数量 |
| `config.ord` | 255 | 域的阶（非零元素数量） |
| `config.irrPolynom` | 283 | 不可约多项式 |
| `config.exp` | table | 指数表 |
| `config.log` | table | 对数表 |
