# Service 模块 - 服务层工具库

## 概述

`service` 目录是 LuCI 应用的服务层模块，提供与后端服务交互相关的工具函数和辅助类。该模块主要用于处理服务调用过程中的错误处理、数据转换等通用功能。

## 目录结构

```
service/
├── Readme.md                           # 本说明文档
└── util/                               # 工具函数目录
    ├── ServiceErrorUtil.lua            # 服务错误工具模块
    └── ServiceErrorUtil.lua.md         # 模块说明文档
```

## 模块说明

### util/ - 工具函数目录

存放服务层通用的工具函数模块。

#### ServiceErrorUtil.lua

**功能**: 提供统一的错误码和错误消息管理功能。

**主要特性**:
- 维护错误码到错误消息的映射表
- 将数字错误码转换为用户友好的错误提示信息
- 支持国际化（i18n）处理

**错误码分类**:

| 错误码范围 | 类别 | 说明 |
|------------|------|------|
| 0-10 | 通用错误 | 参数相关错误 |
| 1000-1999 | 设备错误 | 设备相关错误 |
| 2000-2999 | 数据中心错误 | 后端服务错误 |

**接口函数**:

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `getErrorMessage(errorCode)` | errorCode: 错误码(数字) | string | 根据错误码获取对应的错误消息 |

**使用示例**:
```lua
local ServiceErrorUtil = require("service.util.ServiceErrorUtil")

-- 获取错误消息
local msg = ServiceErrorUtil.getErrorMessage(1056)
-- 返回: "invalid device id"
```

## 依赖关系

- **LuCI 国际化框架**: 使用 `_()` 和 `translate()` 函数进行错误消息的本地化处理

## 设计原则

1. **统一错误处理**: 所有服务层错误通过统一的错误码进行管理
2. **国际化支持**: 错误消息支持多语言翻译
3. **用户友好**: 将技术性错误码转换为用户可理解的提示信息
